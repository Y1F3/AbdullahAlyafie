موقع عبدالله اليافعي — نسخة جاهزة للربط والنشر
============================================

الملفات
-------
index.html       الصفحة العامة للموقع
styles.css       التصميم والألوان والتجاوب
app.js           تحميل المحتوى من Supabase وعرضه
admin.html       صفحة لوحة التحكم
admin.js         منطق تسجيل الدخول والحفظ والإدارة
config.js        رابط Supabase والمفتاح العام وروابط التواصل
upgrade.sql      ترقية قاعدة البيانات والسياسات والإعدادات

مهم قبل النشر
-------------
1) افتح config.js.
2) استبدل YOUR_PROJECT_ID برقم/اسم مشروع Supabase الموجود في رابط مشروعك.
   مثال شكل الرابط: https://xxxxxxxxxxxxxxxx.supabase.co
3) استبدل YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY بالمفتاح العام anon/publishable من Supabase > Project Settings > API Keys.
   لا تضع service_role أو secret key في أي ملف موقع.
4) ارفع الملفات كلها إلى جذر مستودع GitHub Pages، وليس داخل مجلد فرعي.
5) من إعدادات المستودع > Pages اختر النشر من الفرع الرئيسي ومن الجذر / (root).
6) افتح رابط الموقع بعد اكتمال النشر.

تجهيز Supabase
--------------
- افتح SQL Editor في نفس مشروع Supabase وشغّل upgrade.sql مرة واحدة.
- أنشئ حساب المدير من Authentication > Users > Add user (بريد وكلمة مرور).
- انسخ User UID من المستخدم الذي أنشأته.
- شغّل هذا الاستعلام بعد استبدال UID بمعرّف المستخدم الحقيقي:

  insert into public.admin_users (user_id)
  values ('PUT-AUTH-USER-UUID-HERE')
  on conflict (user_id) do nothing;

- إذا كان جدول admin_users القديم عندك مختلفًا أو كان لديك مدير موجود مسبقًا، لا تنشئ سجلًا مكررًا؛ تحقق من الجدول أولًا.
- تأكد من أن بريد المدير موثّق إن كان مشروع Supabase يشترط التحقق من البريد.

فتح لوحة التحكم
----------------
افتح: https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY/admin.html
ثم سجّل الدخول بحساب المدير الذي أنشأته في Supabase.

ما يمكن تعديله من لوحة التحكم
-----------------------------
- النصوص الأساسية والبريد وصورة الواجهة.
- الألوان الأساسية والثانوية، الخط، أحجام الخطوط، استدارة البطاقات، المسافات وعرض المحتوى.
- إظهار/إخفاء أقسام الموقع وترتيبها.
- إضافة وتعديل وحذف الأعمال والخدمات والخبرات.
- رفع صور الواجهة والأعمال إلى Storage.

ملاحظات مهمة
-------------
- هذه نسخة ثابتة تستعمل Supabase مباشرة من المتصفح؛ مفتاح anon/publishable مصمم للاستخدام العام، والأمان يعتمد على سياسات RLS وحساب admin_users.
- لا تشارك مفتاح service_role/secret مطلقًا.
- التعديلات البنيوية الكبيرة (مثل إضافة قسم جديد غير موجود) تحتاج تعديلًا في HTML/JavaScript؛ لوحة التحكم تتحكم بالأقسام الموجودة حاليًا.
- لو كانت الجداول الموجودة عندك بأسماء أعمدة مختلفة جدًا، قد تظهر رسالة خطأ عند الحفظ. لا تحذف الجداول القديمة؛ أرسل نص الخطأ كما يظهر وسنصلح التوافق بأمان.
- قد تكون لديك سياسات RLS قديمة؛ هذا الملف ينشئ سياسات بأسماء محددة، ولا يحذف كل السياسات القديمة تلقائيًا.
